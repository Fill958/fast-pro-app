# Личный Telegram-помощник для учёбы и работы

Один бот, внутри которого работают агенты:

| Агент | Что делает | Статус |
|---|---|---|
| 📅 Расписание | Утренняя сводка, напоминание перед каждой парой, /today /tomorrow /week | ✅ готов (MVP) |
| 📚 Дедлайны | Читает календарь Moodle (stud.lms.tpu.ru), напоминает за 3 дня и за 1 день, /deadlines, кнопка «💡 Совет» | ✅ готов (нужна ссылка на календарь) |
| 📧 Почта | Читает Gmail, Яндекс и почту ТПУ, раскладывает письма по категориям, сразу пишет о важных, сводка в 9:00 и 18:00, /mail | ✅ готов (нужны пароли приложений) |
| 🗓 Планировщик дня | Собирает пары + дедлайны + письма в план на день | 💡 идея |

## Как запустить на своём компьютере (5 шагов)

1. **Создай бота.** В Telegram открой @BotFather, отправь `/newbot`, придумай имя. Он пришлёт **токен** (длинная строка вида `123456:ABC...`).
2. **Узнай свой ID.** Напиши боту @userinfobot, он ответит числом, это твой ID.
3. **Установи Python 3.11+** с python.org (при установке на Windows поставь галочку «Add to PATH»).
4. **Настрой проект.** В папке проекта:
   ```bash
   pip install -r requirements.txt
   ```
   Скопируй файл `.env.example` в `.env` и впиши туда токен и ID.
5. **Запусти:**
   ```bash
   python -m bot.main
   ```
   Напиши своему боту `/start`.

## Как поменять расписание

Открой `schedule.json` и впиши свои пары по дням недели (`mon`, `tue`, ...). Бот перечитывает файл сам, перезапуск не нужен.

## Как подключить дедлайны из Moodle

1. Зайди на stud.lms.tpu.ru → **Календарь** → внизу **«Экспорт календаря»**.
2. Выбери «Все курсы», период «Недавние и следующие 60 дней», нажми **«Получить адрес календаря»**.
3. Скопируй ссылку в `.env` в строку `MOODLE_ICAL_URL=`.
4. По желанию: чтобы работала кнопка «💡 Совет», получи ключ на console.anthropic.com и впиши его в `ANTHROPIC_API_KEY=` (это платно, но копейки за один совет).

Бот проверяет календарь каждые 3 часа.

## Как подключить почту

Бот только **читает** письма: не удаляет, не отвечает и даже не помечает их прочитанными.
Для каждого ящика нужен **пароль приложения**. Это отдельный пароль только для бота, твой обычный пароль ему не нужен.

**Gmail**
1. Включи двухэтапную проверку: myaccount.google.com → Безопасность.
2. Открой myaccount.google.com/apppasswords, придумай имя «Telegram bot», нажми «Создать».
3. В `.env`: `GMAIL_USER=твой@gmail.com`, `GMAIL_PASSWORD=` 16 букв, которые показал Google.

**Яндекс**
1. id.yandex.ru → Безопасность → **Пароли приложений** → «Почта» → создай пароль.
2. В настройках Яндекс Почты: Все настройки → Почтовые программы → включи «С сервера imap.yandex.ru по протоколу IMAP».
3. В `.env`: `YANDEX_USER=твой@yandex.ru`, `YANDEX_PASSWORD=` созданный пароль.

**Почта ТПУ**
Адрес сервера я указал `mail.tpu.ru`, но его нужно проверить (спроси в техподдержке ТПУ «IMAP-сервер для почты»). Самый простой вариант, если не заработает: включи в почте ТПУ **пересылку на Gmail**, и бот увидит эти письма через Gmail.

Если ящик не нужен, просто оставь его строки в `.env` пустыми.

Сортировка по категориям работает лучше всего с ключом Claude (`ANTHROPIC_API_KEY`). Без ключа бот просто отделяет письма от tpu.ru от остальных.

## Файлы

- `bot/main.py` — запуск бота, подключает агентов
- `bot/agents/schedule.py` — агент расписания
- `bot/agents/deadlines.py` — агент дедлайнов Moodle
- `bot/agents/mail.py` — агент почты
- `bot/llm.py` — общий доступ к Claude
- `bot/config.py` — настройки из `.env`
- `schedule.json` — твоё расписание

⚠️ Файл `.env` никому не показывай и не загружай на GitHub: там токен бота.
